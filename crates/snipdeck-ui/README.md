# snipdeck-ui

Design tokens, the Slint component library and the headless test harness. Spec: `DESIGN.md` (§2 colour,
§3 type, §4 components, §5 layout, §6 depth, §7 do/don't, §8 responsive + motion).

## Layout
- `ui/theme.slint`: `Theme` (resolved semantic colours, high-contrast aware), `Type`, `Space`, `Radius`, `Motion`,
  `Fonts`, `SystemLook` (platform-set inputs). `tokens.slint` is generated by `build.rs` from `design/tokens/palette.json`.
- `ui/icons.slint`: `Icons.<name>` (Phosphor Regular SVGs in `icons/`; add a file, run `python3 scripts/ui_icons.py`).
- `ui/components/*.slint`: one component (or tight family) per file. Export each from `ui/components.slint`.
- `ui/gallery/*.slint`: one `export component <Group>Gallery inherits Window` per group showing every variant and
  state; export it from `ui/lib.slint`. Screenshot tests render these.
- `src/testing.rs`: `Harness` (software renderer, frozen clock), `Frame::pixel`, `assert_golden`.

## Component rules
- Colours only through `Theme.*`; sizes through `Space`/`Type`/`Radius`; durations through `Motion`. No hex literal,
  no radius outside 4/6/8, no font size outside the scale, no `#000`/`#fff`.
- Every interactive component: hover, pressed, disabled, keyboard focus (2px `Theme.focus-ring`, 2px offset, shown
  on keyboard focus only: `FocusScope { focus-on-click: false }`), and `accessible-role` / `accessible-label`
  (+ `accessible-action-default`). Hit target at least 24x24, default 28.
- Never convey meaning by colour alone (icon or text too). High contrast works because components use `Theme.*`.
- Text uses `Fonts.sans` (or `Fonts.mono` for keycaps, code, placeholders). No hard-coded strings in reusable
  components: take `in property <string>` (the app translates with `@tr`).
- Animations use `Motion.*` (they become 0ms under reduced motion).

## Tests (tests first)
- `tests/<group>.rs` screenshots: `Harness::new(Gallery::new, w, h)`, then `assert_golden("<group>-light", &h.render())`;
  dark: `h.component.set_dark(true)`. Create goldens with `UPDATE_GOLDEN=1 cargo test -p snipdeck-ui`, then
  **look at each PNG** (Read tool) and fix what is wrong before committing it.
- Measure, don't guess: assert specific pixels (`Frame::pixel`) or sizes for claims such as "focus ring is 2px".
- `tests/<group>_logic.rs` behaviour via `i_slint_backend_testing` (`init_integration_test_with_mock_time`, then
  `ElementHandle::find_by_accessible_label(..).filter(role)`; `invoke_accessible_default_action`, `single_click`).
  One process per test file, so never mix this with `Harness` in one file.
- Time never comes from the real clock: `Harness::advance(Duration)` or `mock_elapsed_time`.
