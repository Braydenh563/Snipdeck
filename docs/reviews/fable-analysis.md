## Architecture redesign (Fable, 2026-10-18)
Measured: `controller.rs` is ~1010 lines of code + ~1280 lines of tests in one file; it owns panel state, picker, fill form, quick capture, paste stack, tray, hotkeys, toasts, settings saving and theme. `binding.rs` (612) mirrors it for one window. Agent A adds Main window logic beside it.
Target shape of `snipdeck-app` (replace, do not layer; each file < 800 lines, tests in sibling `tests.rs` files like `snipdeck-core`):
```
controller/mod.rs      Controller facade: new, view(), on_hotkey, on_tray, on_target_changed, show/hide/close, Effect, Library trait
controller/panel.rs    impl Controller: query, selection, tabs, board menu, add_list, activate/quick use
controller/picker.rs   impl Controller: open/close/query/scope/move/take/use
controller/fill.rs     impl Controller: open/changed/cancel/submit (prompted templates)
controller/stack.rs    impl Controller: quick_capture, paste_next (paste stack)

controller/settings.rs impl Controller: update_settings, set_theme, saver polling, look
controller/tests/*.rs  the existing tests, split by the same seams
main_window.rs         MainModel (Slint-free view-model) + MainActions impl (agent A)
maintenance.rs         startup/daily jobs: trash purge (30 d), backup (24 h, keep 7, encrypted when keyed), integrity check (weekly), crash-log rotation
```

## UX: instinctive without a guide (design decisions, owner ask 2026-10-18)
Principle: every control answers "what happens if I click?" before the click, and the first five minutes teach by doing.

- U2 **The Target footer is the main teacher**: it always reads "Click pastes into Notepad" / "Click copies (no text field in front)"; when the user hovers a row it switches to the row's concrete verb; Shift held changes it to "Shift+click copies". One line, verb first.

- U5 **Discoverable power features**: the row's hover `⋯` opens the same context menu as right-click (Paste, Copy, Paste as plain text, Edit Ctrl+E, Pin, Move to, Delete Del); keyboard users get Shift+F10. Menus show shortcuts so they are learnt in passing.

Click to Do is Copilot+ only and replaced "suggested actions" (https://www.techradar.com/computing/windows/windows-11s-suggested-actions-feature-is-headed-to-the-microsoft-graveyard-but-heres-whats-replacing-it).
- Clipboard formats: Windows honours `ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory` and `CanUploadToCloudClipboard` (https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-formats). When Snipdeck writes a Sensitive item (or restores the clipboard after a paste) it should set all three, so Win+V and cloud sync never see it. SPEC 5.6 covers reading these, not writing them.
- The WinRT `Clipboard` class works only while the caller is focused (https://learn.microsoft.com/uwp/api/windows.applicationmodel.datatransfer.clipboard); a non-activating Panel must use Win32 (`AddClipboardFormatListener`), not WinRT history.
- UIPI: `SendInput` into an elevated window fails silently, with no error code (https://msdn.microsoft.com/en-us/library/windows/desktop/ms646310(v=vs.85).aspx). The "Couldn't paste into Task Manager" toast therefore needs a pre-check of the target's integrity level, not a failure return.
- Windows 11 26H1 ships only on new devices (not an update for 24H2/25H2); KB5101717 (14 Jul 2026) changes hotkey unregister and cleanup behaviour (https://support.microsoft.com/help/5101717). Re-test `RegisterHotKey` re-registration after sleep and on app restart. No 2025-2026 change to UIA or DPI APIs found; unverified.
- Signing (https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options): Store MSIX is re-signed free with no SmartScreen warning; Store EXE/MSI needs your own cert; Azure Artifact Signing is about $10/month but individuals only in the USA and Canada; EV no longer bypasses SmartScreen (since 2024); OV is $150-300/year plus an HSM; SignPath Foundation signs open-source projects free. Store individual accounts are now free worldwide (ID plus selfie check; https://alternativeto.net/news/2025/9/microsoft-finally-drops-microsoft-store-publishing-fee-for-individual-developers-globally). Unverified: whether a Store MSIX can run global hooks and `SendInput` paste (full-trust), and AV false positives for key-injection tools; test before choosing the channel.
- Lookalike malware sites impersonate popular clipboard tools (Maccy README warns of maccyapp.net/.com): publish one canonical domain, winget manifest and file hashes from day one.
