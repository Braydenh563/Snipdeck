# Security and reliability review (Sonnet reviewer, read-only, 2026-10-18)

Scope: launcher PowerShell, maintenance.rs, crash.rs, native_window.rs, frame.rs, panel_geometry. Windows behaviour unverified. Each item is ticked with its commit.

- [ ] 1. MEDIUM-HIGH data safety. maintenance.rs:349 passes `data_key(store)`, None after `lock_key_ring` (keys.rs:156); backup.rs:133 then uses `SensitivePolicy::Skip`, :124 skips a second run the same day, :138 keeps 7. An idle-locked tray app writes sensitive-less backups and after 7 days the last complete one is gone. Fix: `ControllerJobs::backup` returns Err("library locked, backup deferred") when a key ring exists and the store is locked, so `last_backup` stays and the tick retries; or never prune when the export skipped sensitive items.
- [ ] 2. MEDIUM privacy. crash.rs:189-195 writes the panic payload (300 chars); a slice panic quotes item text ("...of `héllo`"); the previous hook echoes it to stderr → launcher logs. Fix: write the message only for a `&'static str` payload; for a `String` write "(message omitted, N bytes)". Correct the module doc.
- [ ] 3. MEDIUM reliability. crash.rs:176-180 names files with local time; `unacknowledged` (:158) and `prune` compare names as strings, so a DST fall-back or travel west hides a new crash or deletes the newest file. Fix: UTC in the file name, local time in the header line only.
- [ ] 4. MEDIUM supply chain. release.ps1:268-293: the `.sha256` sidecar comes from the same release as the zip; `release-sha256.txt` has no pins; "latest" is never pinned. Fix: an unpinned zip needs an explicit y/N (non-interactive: refuse) unless `--allow-unpinned`; commit the pin before publishing. release.ps1:40 checks only the `https://` prefix, not the host (low).
- [ ] 5. MEDIUM data safety. release.ps1 `Invoke-ReinstallPrebuilt` raw-deletes `app\` before a download is known to work, does not stop a running snipdeck.exe, bypasses `Remove-KnownPath` (reparse-point refusal, core.ps1:207), and in a checkout calls `Invoke-CleanBuild $false` (deletes target\ with no prompt). Fix: prebuilt path = stop the app, then `Install-PortableApp` (atomic swap, as update does); checkout path = ask before cleaning the build.
- [ ] 6. MEDIUM. core.ps1:248 `Get-AppProcesses` matches only `snipdeck-app`, not `snipdeck.exe`; restore (data.ps1:213), backup (:160) and clean (:349) proceed while the portable app runs. Fix: return both names.
- [ ] 7. LOW-MEDIUM. `echo %cmdcmdline% | find /i "%~nx0"` is unquoted in Snipdeck.bat:18 and every wrapper (line 12): a folder with `&`, `^`, `|`, `%` runs text as a command. Fix: `set "CL=%cmdcmdline:"=%"` then `call set "R=%%CL:%~nx0=%%"` and `if not "%R%"=="%CL%"`. Wrappers must also require `%~dp0..\..\snipdeck.ps1` to exist before calling `..\..\..\Snipdeck.bat`.
- [ ] 8. LOW-MEDIUM. build.ps1:521 builds `cmd /d /s /c ""exe" ARGS >out 2>err"`; pass-through args with `&` run commands (`Snipdeck.bat run "x&calc"`). Fix: start the exe directly with `Start-Process -RedirectStandardOutput` (as the non-Windows branch :527 does) or reject `& | < > ^ %` in app args.
- [ ] 9. LOW-MEDIUM. core.ps1:684-688 runs `%TEMP%\snipdeck-vs_BuildTools.exe` elevated from a fixed user-writable path with only an MZ check (:622); same for rustup-init (:660). Fix: GUID folder + `Get-AuthenticodeSignature` Status Valid with the expected publisher before running.
- [ ] 10. LOW privacy. lib.ps1:60 `Hide-UserName` is case-sensitive and misses `/` and 8.3 forms; `Write-Log` (core.ps1:70) never scrubs; RepoRoot, exe path and app stdout are logged, and users are told to send the log. Fix: scrub inside Write-Log/Write-LogRaw (OrdinalIgnoreCase, both slashes).
- [ ] 11. LOW. data.ps1:264 `Test-BackupZip` does not require `snipdeck-backup.json`. Fix: require the manifest.
- [ ] 12. LOW, unverified (Windows). main.rs:414 reports every `Moved`; panel.rs:168-180 clamps wholly inside the current monitor and answers `PlaceWindow` on any change, so a Panel straddling two monitors is pulled back and may never cross; rounding differences could loop. `monitor_of` uses the full monitor rect, so the Panel can sit under the taskbar. Fix: clamp on `Resized` and on move end only; use `GetMonitorInfo.rcWork`. (After the step 8 merge.)
- [ ] 13. Missing tests: selftest.ps1 has no test for `Test-SourceCheckout`, `Invoke-ReinstallPrebuilt`, or the release unpack entry-name check beyond the one assert at :80.

Checked clean: zip-slip on restore and unpack; download to a GUID temp dir, hash before extraction, atomic app.new/app.old swap with rollback; TLS 1.2 minimum; `ConvertTo-ArgString` for Invoke-Native; delete guards (`Remove-KnownPath`, `Test-PathUnder`, `Get-NormalPath`); maintenance.rs atomic state write, clock-set-back handling, prune never touching the current file; crash.rs rotation by strict name, append per second, try_lock; frame.rs i64 math and saturating casts; panel_geometry sanitising. Caveat: `Remove-OwnedFolder` registers whatever path it is given as owned.
