# ADR-0005: GPL-3.0, Pro tier via offline key, CLA

- Status: Accepted (2026-10-17)

## Decision
- Code licensed **GPL-3.0-only** (replaces AGPL, whose network clause is irrelevant to a desktop app).
- One codebase. **Pro** features (prompted templates, sensitive encryption + master password, floating lists, >3 boards) unlocked by an **offline Ed25519-signed licence key**; no phone-home, no DRM.
- Contributors sign a **CLA** so the project can be dual-licensed later.

## Consequences
Anyone can rebuild without the check — accepted; buyers pay for convenience (Store, signed builds, updates) and to support the project.
