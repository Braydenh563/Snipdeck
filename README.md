# Snipdeck

A sticky-note-style snippet deck for your desktop: keep the things you paste all the time one click away, and paste them straight into whatever you were typing in.

- Spec: [`docs/SPEC.md`](docs/SPEC.md)
- Decisions: [`docs/adr/`](docs/adr/)
- Architecture: [`docs/architecture.md`](docs/architecture.md)
- Contributing: [`CONTRIBUTING.md`](CONTRIBUTING.md)

Status: design phase. Licensed GPL-3.0.

## Testing the M0 prototypes on Windows

Double-click `run-windows-tests.bat` (see [`tools/windows-test`](tools/windows-test/README.md)). It builds each prototype, walks you through the manual steps and copies a summary to paste back.
